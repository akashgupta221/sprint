## Direction contract

**THESIS:** Crisp Navy Playbook. This page owns one idea: momentum you can watch, on a clean light canvas. It refuses the category default — white SaaS grid with a violet-gradient hero and rows of clone cards — and instead demonstrates Sprint's real machinery (board tempo, durable outbox, contract pipeline) inside the reference app's light navy shade family.

**OWN-WORLD:** Light cool-paper ground (#F9FBFA), white cards, hairline #DDE3E1 borders, slate-navy ink (#242E42), navy primary (#314C81) buttons, and one bright blue accent (#3B82F6) for highlights, links, and the diagram. Faces: Archivo (variable, expanded) for display — athletic, timed-track voice; Geist for text; Geist Mono strictly for measurements, file names, and spec names. Radii 14px; soft navy-tinted shadows with offset; structure via hairlines.

**STORY:** Visitor understands Sprint is agile project management with an engineering-grade backbone (kanban, sprints, notifications that survive restarts and retries); believes it because the page demonstrates the board tempo, the durable outbox, and the one-contract pipeline; acts by starting free or opening the app.

**FIRST VIEWPORT:** Full-bleed GradientWaves in light mode (navy-family silk: horizon #314C81, body #3E5C99, crest #7FA3E0) fills the hero behind everything; floating blur navbar (mark + wordmark left, links center, auth right); display headline, accent phrase in bright blue, ≤4.6rem, left-aligned; subcopy ≤65ch; navy primary pill + ghost secondary; mono data strip of real spec names anchored at the hero's bottom edge.

**FORM:** Single-scroll narrative, code-led. One authored motion moment: the hero (wave intro + headline clip-reveal + CTA rise). Elsewhere varied and quiet: clip-reveal panels, 40ms staggered rows, connectors that draw when seen. Board mock and pipeline data are labeled illustrative.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
